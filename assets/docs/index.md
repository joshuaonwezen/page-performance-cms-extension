# Page performance

## Setup
Fill in either section, or both.

1. **Google Analytics 4**: the numeric property ID and a service account key (JSON). Add the
   service account's email as a Viewer on the property.
2. **Feature Experimentation**: a personal access token (read access is enough), the project ID, and
   the environment whose rules to show (production by default).

## Using it
Open a page and open the **Page performance** tab on the right-hand rail. It shows the last 28 days
of GA4 traffic for the page's URL, and every FX experiment rule that targets it, with results.
