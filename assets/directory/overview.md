# Page performance

See how the page open in the editor performs, without leaving the CMS.

- **Page performance** sidebar:
  - GA4 page views, users, engagement and key events for the last 28 days against the 28 before,
    a daily chart, and the top sources;
  - the Feature Experimentation A/B tests that target the page, with their results.

GA4 and FX are each optional: the sidebar shows whichever you configure. Experiments are found from
FX alone: CMS-driving flags (`cms_flag`) whose `cms_route` covers the page's path.
